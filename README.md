# JurisAI

JurisAI is a modern, dashboard-driven web application built with Next.js, Tailwind CSS, and Recharts, designed to provide seamless analytics and user interface management.

## Features

* **Interactive Dashboard:** Real-time data visualization and metrics tracking powered by Recharts and Lucide icons.
* **Modern UI & Styling:** Styled with Tailwind CSS for a fully responsive, clean interface.
* **Component-Driven Architecture:** Built using Next.js App Router (`app/page.tsx`) and modular components.
* **Type-Safe Development:** Written entirely in TypeScript for robust error checking and maintainability.

## Project Structure

* `src/app/` - Next.js App Router pages and layouts (including dashboard views).
* `prisma/` - Database schema and configuration.
* `tailwind.config.js` - Tailwind CSS styling configuration.
* `tsconfig.json` - TypeScript compiler configurations.

Run `npm install`, `npx prisma db push`, and `npm run dev`.
